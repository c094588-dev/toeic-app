## 単体テストが担保すること

- `learning.ts`: 間隔反復の更新（段階の上げ下げ、遅延ボーナス、時期前の据え置き、答えを見ずに覚えた＝段階 3、判定なしの `touch`、クイズ正解の扱い）、今日の学習の構成（復習 → 新しい単語、新しい単語の上限 10、最低 4、「さらに 10 語」で上限を超える、おさらい、目標より上のレベルを出さない、今日学習した語を出さない、復習に失敗しても新しい単語の上限が減らない、見ただけの語を今日の学習数に数えない）、4 択の生成（語義の重なる語を除外、選択肢 4 つ、教材が空でも落ちない）、保存形式（version 1／2 の読み込み、不明 ID の除外、壊れたデータの検出、更新で時期が来た語の 14 日分散、未来の時刻の丸め）、単語データ（1,500 語、ID 一意、例文と訳がそろう）。
- `session.ts`: 途中位置の保存・復元、別の日・壊れた値・消えた単語の扱い。
- `days.ts`: 日ごとの記録、7 日の点、最後の学習からの日数、その日の目標の読み込み。
- `review.ts`: レビュー依頼のタイミング（3 回目から、120 日間隔、年 3 回）。
- `listen.ts`: 読み上げの順番と間、停止・一時停止。
- `customWords.ts`: 入力の検証、重複の検出、保存形式。
- `premium.ts`: 課金が無効で、全機能が無料のまま。
- `cloze.ts`: 例文の穴埋め。

## 既知の制約

- Web 版（Safari）は 7 日間操作のないサイトの localStorage を消すことがある。ホーム画面に追加すれば対象外。
- Web 版の `index.html` は `lang="en"` のまま（Expo の設定項目が見つからず、未対応）。
- 耳だけ復習の日本語音声は、Web ではブラウザに ja-JP の音声がない環境がある。
- `requestReview` は Web では出さない。
- 今日の目標語数はその日に初めて組んだ語数で固定し（`toeic.goal.v1`）、目標スコアを変えたときだけ組み直す。出せる語が尽きたら達成とみなす。
- 判定の直後 250ms は次のカードの判定を受け付けない（連打で 2 枚進まないため）。自動操作でカードを連打するときは 300ms 以上あける。
