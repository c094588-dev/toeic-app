## 第三者監査（エージェント G）

- 判定: **条件付き Go**。P0（データ消失・クラッシュ・致命的誤動作）は確認できず。保存形式の互換、中断再開、取り消し、SRS の境界、耳だけ復習の競合、連打ロックを個別に検証。
- P1 4 件と Go 条件 10 件（すべて修正済み）:

| # | 指摘 | 対応 |
| --- | --- | --- |
| P1-1 | VoiceOver では答えを出す操作がない | ヒントの行を「意味を見る／英単語を見る／次のカードへ」のボタンにした（E2E で存在を確認） |
| P1-2 | 目標チップが「500／点」と 2 行に折れる | チップを数字だけ・1 行固定・左右の余白を 8pt に（E2E で高さ ≤ 52 を確認）。読み上げは「目標スコア 500 点」のまま |
| P1-3 | 今日の目標の分母が途中で縮む／再開ボタンと食い違う。失敗した復習が新語枠を食う | 目標はその日に初めて組んだ語数で固定し、出せる語が尽きたら達成。新しい単語は「初めて記録が付いた日」（`first`）で数え、失敗した復習は数えない。初回文言を直した |
| P1-4 | 答えを見てタップで流すだけで「達成」になり新語枠も消費 | 見ただけの語は今日の学習数にも新語にも数えない（同じ日にもう一度出さないだけ）。ヒントを「タップで飛ばす」に |
| P2-1 | 操作ヒントが消えない（`<=`） | `<` に |
| P2-2 | 「さらに 10 語」が固定文言 | 出せる語数を表示 |
| P2-3 | 結果画面の題と見出しが重複 | 題を「学習の結果」に |
| P2-4 | 7 日の点の空円が見えにくい | 枠を `border`（3.5:1）に |
| P2-6 | 「覚えた」の連打で次のカードも判定 | 判定後 250ms はロック |
| P2-9 | 達成の触覚とレビュー依頼が 20 語固定 | その日の目標で判定 |
| P2-10 | 目標スコアを変えても目標語数が変わらない | 変えたら組み直す |
| P2-15 | CLAUDE.md が存在しない docs を参照 | docs を作成 |
| P2-16 | レベル別の途中位置が「続きから」に出ると分かりにくい | ボタンにレベル名を添える |

- 未対応（[NEXT_ACTIONS.md](NEXT_ACTIONS.md) に記載）: Reduce Motion 時のスタンプ、最後のカードの取り消し、耳だけ復習の一時停止後の読み直しと「まだ」の取り消し、「おさらい」が数語で終わる日の文言、Ionicons フォントの軽量化、苦手の数え方の統一。

## 安全性

- ユーザーデータの削除なし（登録単語の削除は 2 段階確認。進捗のリセット機能なし）。本番のデータベースはない（端末内のみ）。
- 課金は無効。既存機能の有料化なし。外部の有料サービスなし。App Store への公開はしていない。
- API キー・証明書・パスワードはコード・ログ・Git にない。CI は検証コマンドだけ。
- 外部サイトの文章は参考情報として扱い、転載していない。TOEIC は ETS の登録商標である旨を設定画面とストア文に記載。
