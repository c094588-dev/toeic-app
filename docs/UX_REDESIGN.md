# UX・デザイン再設計（英単語ノート 1.1）

作成日: 2026-10-25。改善前の画面は git タグ `before-redesign`、改善前後のスクリーンショットは [IMPLEMENTATION_REPORT.md](IMPLEMENTATION_REPORT.md) を参照。

## 改善前の問題（確認済み）

- 学習画面: 単語 40pt が白いカードの中で画面の上 1/3 に押し込まれ、その下に画面の 37〜54% が空白。操作説明が常時 2〜3 行。SE では「左で「ま／だ」」と折り返しが崩れていた。
- ホーム: キャッチコピー 2 行＋「覚えた単語 0 / 1,500」が最上段を占め、主ボタンは SE で画面下端ぎりぎり（y≈571pt）。ページ全体は 2.4 画面分。
- 学習の途中位置が保存されず、中断すると別の 20 語が「1 / 7」から始まる。
- 答えを見たあとのタップは「記録なしで次へ」。タップだけで進めると今日の学習数が増えない。
- 誤スワイプの取り消しがない。
- 結果画面は「ひと区切り、完了。」の一文だけで、何語覚えて何語がまだかが出ない。
- Dynamic Type・Reduce Motion・VoiceOver の見出し／読み上げが未対応。4 択は SE で選択肢 D が画面外。
- 文字サイズ 13 種、角丸 7 種、余白 9 種が混在。絵文字アイコン（🔊）。

## 利用シナリオと操作数（改善後）

| シナリオ | 操作 | 改善後の体験 |
| --- | --- | --- |
| 通勤電車で 1 分（30 秒〜1 分） | 1 タップで開始、1 枚 2 操作 | どこで閉じても次回は「続きから（9 / 20）」。判定した分は 1 語ごとに保存 |
| エレベーター待ち 30 秒 | 1 タップ、3〜4 枚 | 答えを見ずに「覚えた」にした語は既知語として 7 日後から（毎日つき合わされない） |
| 昼休みに 3 分集中 | 1 タップ → 20 枚 → 結果 | 結果画面に「まだの単語をもう一度（3 語）」「さらに 10 語」「今日はここまで」 |
| 電話で中断 → 数時間後 | 1 タップ | 同じ日なら同じ列・同じ位置から。日付が変わればその日の計画で組み直す |
| しばらくぶり（7 日以上） | 1 タップ | 「おさらいから始める」。新しい単語は出さず、覚えた単語の復習だけ |
| 苦手だけ | 1 タップ | ホームの「苦手だけ復習（N 語）」（レベル横断、苦手が 1 語以上のときだけ） |
| 手が使えない | 1 タップ | 「耳だけ復習」: 単語 →（思い出す間）→ 意味 → 例文を自動で読み上げ。一時停止・次へ・「まだ」 |

## ホームの主ボタン（状態遷移）

主ボタンは常に 1 つ。控えめなボタンは最大 1 つ。

| 状態（判定順） | 主ボタン | 添える一言 |
| --- | --- | --- |
| 目標未設定（初回） | （チップ 500〜900） | 「目標に合わせて、復習と新しい単語を毎日選びます（1 日 20 語まで。新しい単語は 10 語まで）。迷ったら 600 点。」 |
| 途中の学習がある | **続きから（9 / 20）** | — |
| 出せる単語がない | （無効）今日出せる単語がありません | 「目標スコアを上げると、新しい単語が増えます。」 |
| 今日の目標を達成 | なし（控えめに **さらに 10 語**） | 「今日はここまでで十分。明日もここから。」 |
| しばらくぶり（7 日以上） | **おさらいから始める（20 語）** | 「しばらくぶりですね。覚えた単語のおさらいから。」 |
| 今日いくらか学習済み | **今日の学習を続ける（8 / 20）** | 内訳（苦手 3 語・復習 5 語・新しい単語 12 語） |
| それ以外 | **今日の学習を始める（20 語）** | 内訳 |

今日の目標は 20 語。出せる単語がそれより少ない日（始めたばかり・復習が少ない日）は出せる分までを目標にし、その日に初めて組んだ語数で固定する（`toeic.goal.v1`）。目標スコアを変えたときだけ組み直す。出せる語が尽きたら達成とみなす。「さらに n 語」は出せる語数を表示する。

## 学習画面（案 A「固定アンカー・枠なし」）

```
┌──────────────────────────────┐
│ ‹        3 / 20          🔈  │ 48pt ヘッダー、進捗 4pt
│                              │
│          prepare             │ display 48/56、上端から約 28% に固定（答え前後で動かない）
│                              │
│  準備する                     │ heading 22/30 ← 答えはこの下に出る
│  They are preparing for ...◁)│ body 17/26 ＋ 44pt の再生
│  彼らは開店に向けて…          │ callout 15/22 muted
│  [苦手] [3日ぶり]             │ バッジ（該当時のみ）
│                              │
│   タップで意味を見る           │ 最初の 3 回の学習だけ（hintsSeen）
├──────────────────────────────┤
│ [◁)] [   まだ   ] [  覚えた  ] │ 56pt、親指圏
│ 「deliver」を覚えたにしました 取り消す │ 判定直後 4 秒
└──────────────────────────────┘
```

- 単語は動かさない、枠を描かない、文字は必要な瞬間だけ。
- 画面のどこでもタップ: 答え前は「意味を見る」、答え後は「飛ばす（判定なし）」。見ただけの語は同じ日にもう一度出さないが、今日の学習数と新しい単語の数には入れない（判定して初めて数える）。VoiceOver 向けに、同じ操作をするボタン「意味を見る／次のカードへ」をヒントの行に置く。
- 左右スワイプ: 90pt またはフリックで「まだ（左）」「覚えた（右）」。横成分が縦の 1.2 倍以上のときだけ（斜めスクロールを記録しない）。しきい値を越えた瞬間に軽い触覚。
- 取り消し: 判定直後 4 秒。進捗・日ごとの記録・途中位置の 3 つを判定前に戻し、前のカードを答えが開いた状態で表示。
- 日本語 → 英語: 意味を同じ位置に出し、答えで英単語。答えを出すまで発音ボタンは押せない（答えが分かってしまうため）。
- Reduce Motion: スワイプの平行移動とスタンプの動きを止める。

## 結果画面

「今日はここまで」（達成時）または「ひと区切り」。数字は **覚えた／まだ／判定なし** の 3 つまで。今日の学習 N / 20 のメーター、明日の予告（復習 n 語・新しい単語 m 語）、励ましは 4 種類を順番に（乱数にしない）。ボタンは「今日の学習を続ける」または「今日はここまで」、「まだの単語をもう一度（n 語）」、達成後は「さらに 10 語」。

## デザインシステム（`mobile/src/theme.ts`、`ui.tsx`）

- 間隔: 4 / 8 / 12 / 16 / 24 / 32 / 48。画面ガター 16、カード padding 24、カード内 gap 16。
- 角丸: 12（チップ・入力）、14（ボタン・選択肢）、20（カード）、pill。影は使わない。
- 文字: display 48、display2 34、title 28、heading 22、numeral 28（等幅数字）、body 17、button 17、callout 15、caption 13。Dynamic Type の上限は 本文 1.6 倍・ボタン 1.3 倍・大きな文字 1.2 倍。
- 色: ライト bg #EEF1EC／カード白（枠なし）、ダーク bg #111B22／カード #1C2932（区切り線 #2A3A42）。アクセント #176F66（ダーク #80DACC）。すべての文字ペアで WCAG AA 以上。
- アイコン: Ionicons（`@expo/vector-icons`）。絵文字・テキスト記号は使わない。ボタンのラベルは動詞のみ。
- 部品: Button（primary 56pt／secondary／tertiary／danger）、IconButton（44 or 56pt、ラベル必須）、Card、Row（64pt、chevron）、Chip（48pt）、Meter（4〜6pt）、Badge、Notice。

## アクセシビリティ

- すべてのボタンに `accessibilityRole="button"` と名前。見出しに `accessibilityRole="header"`。
- 44pt 以上のタップ領域（E2E で機械確認）。
- 大きな文字: `maxFontSizeMultiplier` で破綻を防ぎ、英単語は `adjustsFontSizeToFit`（Web は幅から計算）。
- VoiceOver: クイズの正誤、取り消しのトースト、登録完了を `announceForAccessibility` で読み上げ。
- Reduce Motion: `AccessibilityInfo` を購読。
- 小さい iPhone（375×667）: 主ボタンと判定ボタンがスクロールなしで画面内（E2E で確認）。

## マイクロコピーの原則

- ボタンは動詞で終えるか「名詞＋数」。状態は数で示す。スローガンは 1 画面に 1 つまで。
- 「まだ」「覚えた」は判定の言葉として固定し、ほかの意味に使わない。
- 表記を統一: 「すべて」「500 点レベル」「「まだ」に戻しました」。
- 文言は `mobile/src/copy.ts` に集約。

## 却下した UX

起動と同時に学習画面へ入る、オンボーディングのカルーセル、連続日数と炎のアイコン、紙吹雪・効果音、前日のセッションの復元、答え表示後のタップを「まだ」扱いにする、判定の強制、上下スワイプ、学習中の「戻る」に確認ダイアログ、ホームにフィルタや学習モードを増やす、Tinder 型カードスタック、タブバー、独自フォント、影・グラデーション。
