# プロダクト戦略（英単語ノート）

作成日: 2026-10-25

## 一言で

**「英単語を覚えるなら、これが一番ラク。」**

開いたら今日の単語。終わったら「今日はここまで」。登録なし・広告なし・通信なし。覚えることだけ。

## 誰のために

- TOEIC 500〜700 点帯の社会人・大学生（受験者の中心層）。通勤・昼休み・寝る前の 30 秒〜3 分。
- 「何をやるか決めたくない」「サブスクは嫌」「設定を覚えたくない」人。
- 競合（[COMPETITOR_ANALYSIS.md](COMPETITOR_ANALYSIS.md)）が「もっとやらせる」方向に進む中で、「ちょうどよく終わる」を求める人。

## 「ラク」の 3 層（設計原則）

| 層 | 意味 | 守ること | 1.1 での実装 |
| --- | --- | --- | --- |
| 操作がラク | 1 タップで始まり、片手で終わる | 設定項目を増やさない。ホームの主ボタンは常に 1 つ | ホーム＝今日の学習カードが最上段。主ボタンの状態遷移（始める／続きから／続ける／おさらい／達成）。画面全体タップ＋左右スワイプ＋ボタン。親指圏のフッター |
| 判断がラク | 何を・何語・どの順かはアプリが決める | 「どれくらいで終わるか」「止めてよい時」を示す | 1 日の目標は 20 語（出せる語が少ない日は少なく）。復習 → 新しい単語の順。「今日はここまで」の結果画面と明日の予告 |
| 気持ちがラク | 責めない、急がせない、押し売りしない | 連続日数・ハート・催促・広告を入れない | 「この 7 日で 4 日」の点。取り消し。しばらくぶりは「おさらいから」。課金は無効のまま |

## 北極星指標と補助指標

- **北極星: 週に 3 日以上「今日の目標」を達成したユーザーの割合**（週間継続）。解析 SDK は入れないので、まずは App Store Connect の継続率（opt-in ユーザー）と、本人・知人での観察で代替する。
- 補助: 初回起動から学習開始までのタップ数（2 以下を維持）、1 セッションの所要（20 語で 3 分前後）、復習の正答率（目標 85〜90%。[LEARNING_DESIGN.md](LEARNING_DESIGN.md)）。
- 出さない指標: 学習時間、累計表示回数、連続日数。

## 1.1 で何を変えたか（要約）

| 優先 | 変更 | 理由 |
| --- | --- | --- |
| P0 | 学習の途中位置を保存し「続きから（9 / 20）」で再開 | 通勤 1 駅で閉じると最初からやり直しだった |
| P0 | 判定の取り消し（4 秒） | 誤って右スワイプすると 7 日間出てこなかった |
| P0 | 答えを見たあとのタップを「見た」として記録（判定なし） | タップだけで進めると今日の学習数が増えなかった |
| P0 | 静かな間隔反復（1→3→7→…→240 日）、復習優先・新しい単語は 1 日 10 語まで | 「覚えた」1 回で確定し、復習は一律 7 日後・1 日 5 語で、数週間で破綻していた |
| P1 | ホーム・学習・結果・レベル・設定の再設計とデザイントークン（9 文字サイズ・4 角丸・4pt 間隔） | 学習画面は単語の下に画面の 4〜5 割が空白、ホームは CTA が SE で下端ぎりぎり |
| P1 | Dynamic Type の上限、Reduce Motion、VoiceOver のラベル・見出し・読み上げ | いずれも未対応だった |
| P1 | 「今日はここまで」の結果画面、7 日の点、しばらくぶりの「おさらい」、苦手だけ復習（レベル横断） | 戻ってくる理由と止める合図がなかった |
| P2 | 耳だけ復習（単語 → 意味 → 例文の自動再生）、レビュー依頼（3 回目の達成後、年 3 回まで） | 手が使えない場面と、ストアでの発見性 |
| P3 | 有料プランの土台（フラグ無効、審査要件を満たす案内画面の雛形） | 課金は始めない。構造だけ |

詳細は [UX_REDESIGN.md](UX_REDESIGN.md)、[LEARNING_DESIGN.md](LEARNING_DESIGN.md)、[IMPLEMENTATION_REPORT.md](IMPLEMENTATION_REPORT.md)。
