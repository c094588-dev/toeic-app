# グロース戦略（英単語ノート）

作成日: 2026-10-25。広告出稿・外部サービスの契約はしていない。ここに書いた施策はすべて提案で、ストアの文言変更は [appstore/README.md](../appstore/README.md) を更新してから App Store Connect で行う。

## 結論

1. 本命は **「学習結果の共有カード」**（X の勉強垢文化に乗る画像共有）、**Web 版 → App Store の導線**（Smart App Banner）、**レビュー依頼の適切なタイミング**（3 回目の達成後。1.1 で実装）。
2. ASO は、名前は変えず、サブタイトルを「習慣訴求」で A/B、キーワード欄の重複を整理、1 枚目のスクリーンショットに「登録不要・広告なし」の帯、App プレビュー動画を追加。
3. 広告出稿は LTV が測れるまで待つ。計測は App Store Connect（＋ `appstore/report.mjs`）で 9 割足りる。汎用の解析 SDK は入れない。

## ASO

| 項目 | 現状 | 提案 |
| --- | --- | --- |
| 名前 | 英単語ノート | 変えない。同名・類似名があれば「英単語ノート - TOEIC®単語帳」を検討 |
| サブタイトル | TOEIC®対策 目標スコア別1500語 | 対案「TOEIC®対策 1日20語で続く単語帳」。1 アップデートに 1 回だけ入れ替え、検索流入で比べる |
| キーワード（100 文字） | 95 文字、「TOEIC」が重複 | `トーイック,英語,暗記,語彙,ボキャブラリー,暗記カード,単語カード,単語テスト,例文,リスニング,発音,クイズ,社会人,大学生,通勤,スキマ時間,オフライン,英単語帳,600点,730点,800点`（99 文字） |
| アイコン | 黄色地に白いカードと「英」 | 変えない（教育カテゴリは青系が多く、一覧で目立つ）。半年後に PPO で検証 |
| スクリーンショット | 1 枚目「目標スコアを選ぶだけで 今日の20語が決まる」 | 1.1 の画面で撮り直し。1 枚目に「登録不要・広告なし」の小さな帯。2 枚目「続きから」、3 枚目「耳だけ復習」、4 枚目「今日はここまで」。App プレビュー動画（15〜30 秒、タップ → 答え → スワイプ → 取り消し） |
| 説明文の冒頭 3 行 | — | 1 行目「目標スコアを選ぶだけで、今日の 20 語」、2 行目「登録不要・広告なし・端末内だけに保存」、3 行目「1,500 語すべて無料」 |
| 新機能（1.1） | — | 「続きから」「取り消し」「忘れるころに出す復習」「耳だけ復習」「今日はここまで」「文字の大きさと VoiceOver に対応」 |
| 特集推薦 | — | ASC の Featuring nomination を日本語で申請（1.1 のアップデートに合わせて） |

商標: 「TOEIC」は ETS の登録商標。表記は現状の「TOEIC®」＋免責文を維持し、投稿でも守る。

## 口コミ・SNS

- **共有カード（次の候補）**: 結果画面に「共有」→ 画像（覚えた語数・今日の達成・7 日の点・アプリ名と URL）を共有シートへ。アカウント不要で成立し、プライバシー方針も崩さない。Web 版は `navigator.share` から。
- **公式アカウント**: 毎日「今日の 1 語」（自作例文）を同じ時間に投稿。TOEIC 公開テストの 2 週間前と結果発表後に投稿量を増やす。
- **Web 版 → App Store**: `<meta name="apple-itunes-app" content="app-id=6824718074">` と、ホーム下部の「iPhone アプリ」リンク。Web 版は無料の入口として残す。
- **レビュー依頼（1.1 で実装）**: 3 回目の「今日の目標、達成」の 1.5 秒後に `expo-store-review`。120 日空ける、年 3 回まで、Web では出さない。設定に「レビューで応援する」リンク（`itms-apps://apps.apple.com/app/id6824718074?action=write-review`）を足すのは次の候補。
- note／Zenn の開発記録は 1 本だけ（開発者層向け、被リンク目的）。

## 計測（プライバシー重視の最小構成）

| 指標 | 定義 | どこで取るか |
| --- | --- | --- |
| DL・再DL・ページ転換率 | — | App Store Connect（全ユーザー）。`appstore/report.mjs` で取得 |
| D1／D7／D30 継続率 | 初回起動から n 日後に起動 | ASC App Analytics（opt-in ユーザーのみ。傾向だけ見る） |
| 学習開始率・完了率・週間継続 | 起動した日のうち始めた日／20 語に達した日／直近 7 日で 3 日以上 | **自前の週次サマリー**（次の候補）: 識別子なしの集計値だけを Cloudflare Workers Analytics Engine に送る。設定でオフ可。App プライバシーと `privacy.html` を同時に更新 |
| 有料転換・解約 | — | 課金を始めたら RevenueCat（または ASC のサブスクリプションレポート） |

入れないもの: Firebase Analytics／Amplitude／Mixpanel（識別子と診断データでラベルが重くなる）。

## Android

個人の Google Play アカウントは「12 名のテスターで 14 日間のクローズドテスト」が本番公開の条件。iOS で課金と継続率が固まってから。コードは Expo のまま流用できる。

## 却下した案

広告（AdMob 等）、ランキング・リーグ、学習系インフルエンサーへの有償依頼、課金が固まる前の Apple Search Ads（出すなら月 1 万円の上限で CPT の学習目的に限る）、スコア別の複数アプリ化。
